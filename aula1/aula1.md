## TÓPICO 1: Elementos da lógica de programação.

A programação é o que dá vida para todos os aplicativos de celulares, editores de texto e muito mais. Para entender como tudo isso funciona vamos estudar o Python, suas principais características, elementos básicos e um pouco da sua história.

Pensar de forma racional é uma característica muito importante da raça humana. Raciocinar é chegar a uma conclusão válida a partir de uma ideia inicial e a um conjunto de regras que conectam a ideia à conclusão. No caso de se inscrever em um curso para obter uma certificação é necessário seguir uma série de passos:

|(Passo 1)|(Passo 2)|(Passo 3)|(Objetivo final)
| :-- | :-- | :-- | :-- |
|Assistir todas as aulas|Estudar o conteúdo|Passar na prova|Certificação|

    Essa sequência finita de passos simples e bem definidos para se resolver um problema se chama algoritmo, eu posso usar esse mesmo algoritmo para alcançar mais de uma certificação de cursos online. Todo algoritmo é composto por três elementos: Entrada, processamento e saída. 

    Em exemplo do algoritmo de cima, a entrada seriam os dados pessoais na matrícula, as respostas das atividades e prova. O processamento seriam as comparações das respostas dadas pelo aluno com as do gabarito, somar e calcular os pontos. Por fim a saídas seriam a nota final e o certificado/ou não. Logo, a entrada são os dados que o sistema/programa/algoritmo recebe do usuário, o processamento seriam os cálculos a serem realizados com os dados recebidos e a saída seriam os resultados desse cálculos. 
    para humanos que conhecem e dominam a linguagem natural, uma ordem como "faça um miojo" é simples, sem ambiguidades, mas num contexto computacional (programação) isso é inviável, é preciso ser mais claro e direto ao dar instruções a serem executadas por um computador. 

    Um computador não compreende linguagem natural(por enquanto, jaja estão substituindo a gente), não é possível criar um programa dando instruções em português ou em outro idioma. Por isso, usamos linguagens de programação, são linguagens menos complexas, mais próximas da máquina do que do homem, aqui será o PYTHON. (Quão mais próxima a linguagem de programação for da linguagem natural, maior será o nível da linguagem.)

TÓPICO 2: A linguagem de programação Python.

    Agora, este tópico abordará sobre os elementos gerais do Python, quando foi desenvolvido, para quem serve, suas principais características e como instalar seu ambiente de desenvolvimento através do anaconda e iniciar o primeiro código em Python para compreender como ele é capaz de resolver diversos problemas computacionais.

    Código-fonte: uma linguagem de programação define um vocabulário e um conjunto de regras para que se possa descrever diferentes algoritmos em forma textual, estes são os elementos formais que podem ser entendidos por humanos e, como já foi apresentado, traduzidos para algo que os computadores entendam. Existem duas formas de tradução: 
    Compilação: Quando o código é traduzido apenas uma vez e gera um arquivo executável específico para aquele sistema operacional.
    Interpretação: Quando o código-fonte é traduzido sempre é executado, podendo ser interpretado por qualquer sistema operacional.  

    Os código-fontes escritos em Python são arquivos com extensão .py, sendo uma linguagem interpretada criada nos anos 1990 por Guido van Rossum, um matemático e programador holandês. O Python  você pode escrever programas com ela para automatizar o seu trabalho, fazer comunicação via internet, criar novas tecnologias e muito mais(Pesquisar sobre o Zen of Python).

Tópico 4: Jupyter notebook.
    
    O Jupyter Notebook é uma aplicação web open-source de ambiente de computação interativa. Ele permite criar e compartilhar documentos digitais (com extensão .ipynb) que contêm código executável, textos explicativos, equações matemáticas e visualizações gráficas no mesmo lugar. Um notwbook jupyter é uma aba aberta no navegador onde há um editor de texto em células onde partes do texto são código-fontes do Python que seram executadas.

    Quando abrir o jupyter, na aba files é só escolher o direttório para criar seus arquivos, para criar o arquivo, clicar na opção new e em Python 3.

    Na barra primeira superior mostra o logo do jupyter, o nome arquivo e o logo do python respectivamente. 

    Logo abaixo, haverá uma barra de menus com diversas opções, como File, Edit, View, Insert, Cell e Kernel. Em baixo dessa barra, há a lista de ações mais comuns para se executar em um notebook Python.

    Existem dois tipos de células(pedaços independentes do notebook), as Markdown e as Code. 

    Markdown:

    As células Markdown são aquelas que você pode editar, e servem como explicação do seu notebook. Para criar um markdown, basta inserir uma ceĺula 
e trocar a opção code para markdown. Células mmarkdown possuem sintaxe própria, dá pra usar marcadores para formatar o texto.
    
    Code:

    As células do tipo code são aonde se estruturam o código-fonte do programa desenvolvido. Esse tipo de célula apresenta um elemento novo. Do lado esquerdo, de onde você edita seu código, aparece um texto “In [ ]:”. Após a execução da célula, aparece um número entre os colchetes, indicando que essa célula foi a primeira a ser executada, ou a segunda, e assim por diante.
